# Neon Horizon | AI & ML Portfolio

A high-performance, immersive portfolio landing page built for **AI & Machine Learning Engineers**. This project features a sophisticated dark-mode aesthetic with refined glassmorphism, 3D interactive elements, and dynamic canvas animations.

![Portfolio Preview](https://github.com/Sujit224/sujit-portfolio/raw/main/public/preview.png)

## 🚀 Technical Highlights

- **3D Interactive Skills**: A sophisticated 3D Coverflow-style carousel built with **Framer Motion** for a premium interaction experience.
- **Neural Network Animation**: A custom HTML5 Canvas engine that simulates a pulsating neural network and agentic workflow in the hero section.
- **Glassmorphic UI**: A modern design system utilizing vanilla CSS and Tailwind for high-end transparency and blur effects.
- **Responsive Architecture**: Fully optimized for all device scales, from mobile to ultra-wide displays.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Animation**: Framer Motion, HTML5 Canvas
- **Styling**: Tailwind CSS, Lucide React
- **Icons**: FontAwesome, DevIcons
- **State Management**: React Hooks

## 📂 Project Structure

- `src/components/`: Core UI components including the Neural Network engine and interactive sections.
- `src/data/constants.js`: Centralized source of truth for all project data, tech stack, and social links.
- `src/styles/`: Global styles and tailwind configurations.

## 📥 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Sujit224/sujit-portfolio.git
   cd sujit-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run in development mode**:
   ```bash
   npm run dev
   ```
